Building Damage Mapping from Remote Sensing Imagery

Macdennis Nwaeze · University of Houston · ECE 6364 Digital Image Processing

Abstract

This project evaluates deep-learning models for automated building-damage mapping from post-disaster satellite imagery. The task was formulated as a five-class semantic-segmentation problem: background, no damage, minor damage, major damage, and destroyed. Using the xView2/xBD dataset, building polygons were converted into dense pixel-wise masks for supervised learning.

A U-Net CNN baseline with a ResNet-34 encoder was compared with the transformer-based SegFormer-B0 architecture under consistent data splits, preprocessing, training, and evaluation. A focused ResNet-50 extension was also tested to determine whether greater CNN depth improved segmentation.

Dataset and Preprocessing

The xView2/xBD multi-disaster dataset contains post-disaster RGB satellite imagery, building footprints, and per-building damage labels. Data were separated by disaster event so that the test set represented unseen disasters. Images and masks were resized to 512×512 pixels, masks used nearest-neighbor interpolation to preserve class labels, and training used normalization plus horizontal and vertical flip augmentation. Class imbalance was addressed using class-weighted cross-entropy combined with multiclass Dice loss.

Models

U-Net + ResNet-34: encoder-decoder CNN with skip connections and an ImageNet-pretrained ResNet-34 encoder.

SegFormer-B0: hierarchical transformer encoder with self-attention and a lightweight decoder designed to capture broader spatial context.

ResNet-50 extension: controlled CNN-depth experiment using a deeper ResNet-50 encoder while holding the remaining workflow constant.

Training and Compute

Models were trained for 30 epochs with batch size 8 using Adam at a learning rate of 1×10−3. Training used CPU and CUDA-enabled NVIDIA GPU environments in Google Colab. Performance was evaluated using mIoU, Dice, macro F1, precision, recall, pixel accuracy, per-class metrics, confusion matrices, and qualitative segmentation results.

SegFormer produced the strongest overall segmentation performance and more spatially coherent predictions. Minor damage remained the most difficult class because of severe class imbalance and subtle visual differences from no-damage imagery.

Discussion

Pixel accuracy alone was not sufficient because the background class dominates the imagery. mIoU, Dice, and macro F1 gave a more balanced view of model behavior. SegFormer benefited from broader spatial context through self-attention, while the ResNet-50 extension improved training stability without materially improving test segmentation. Major failure modes included small-building misses, boundary confusion, visually similar damage levels, and cross-event generalization.

Conclusion

The project demonstrates an end-to-end deep-learning workflow for post-disaster building-damage mapping. Transformer-based SegFormer achieved the best overall balance of segmentation accuracy and spatial coherence, while increasing CNN depth alone did not resolve the core limitations associated with local context and class imbalance.
